# StoryVoice AI 🎙️📖

StoryVoice AI is a simple web application that converts written stories into spoken narration using Text-to-Speech technology.

Users can enter a story, upload a TXT file, control voice speed and volume, and listen to the story being narrated.

## ✨ Features

- 🎙️ Text-to-Speech story narration
- 📄 Upload TXT story files
- ✍️ Enter or edit stories directly
- ⚡ Adjustable speech speed
- 🔊 Adjustable voice volume
- 📊 Word and character statistics
- ⏱️ Estimated reading time
- ▶️ Play narration
- ⏹️ Stop narration
- 📱 Responsive user interface
- 🎨 Modern purple and blue UI

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask
- pyttsx3
